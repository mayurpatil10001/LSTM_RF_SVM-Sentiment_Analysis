# 📈 StockSense AI — Sentiment-Powered Stock Predictions

**StockSense AI** is a state-of-the-art stock price prediction dashboard that combines traditional financial modelling with Deep Learning and Natural Language Processing. It fetches live Indian market data, performs real-time sentiment analysis on financial news using **FinBERT**, and generates price forecasts using a hybrid of **LSTM**, **Random Forest**, and **Support Vector Regression (SVR)**.

---

## 🚀 Key Features

- **Live Data Pipeline**: Integrated with `yfinance` to fetch OHLCV (Open, High, Low, Close, Volume) data for any Indian ticker (NSE/BSE).
- **FinBERT Sentiment Engine**: Uses the `ProsusAI/finbert` transformer model (specifically trained on financial corpora) to analyse news headlines and descriptions.
- **Hybrid AI Models**:
  - **Deep Learning (LSTM)**: A 6-feature hybrid LSTM (Price + Sentiment) for capturing long-term dependencies.
  - **Machine Learning (RF & SVM)**: Robust regression models incorporating 9 features (Price + Sentiment + Moving Averages).
- **Advanced Dashboard**:
  - Multi-tab navigation.
  - Dark-themed Interactive charts (Price, Sentiment Timelines, Model Comparison).
  - Sentiment distribution and correlation visualisations.
- **Ticker Auto-Mapper**: Seamlessly handles NSE tickers and BSE equivalents.

## 🛠️ Implementation Details & Recent Fixes

Recently, the system underwent a major overhaul to resolve critical issues and enhance performance:

1.  **News API Integration (Fixed)**: 
    - Resolved **HTTP 422 errors** caused by unsupported date filtering on the `newsdata.io` free plan.
    - Implemented an intelligent search query builder (`Ticker + Company Name`) to maximise news relevance.
    - Added pagination support to fetch up to 50 recent articles per run.
2.  **LSTM Model Stability (Fixed)**: 
    - Added **Input Shape Validation** to ensure the saved model checkpoints are compatible with the current feature set.
    - Implemented **Automatic Retraining** when switching between tickers to ensure the `MinMaxScaler` parameters remain accurate to the specific stock's price range.
3.  **Data Synchronisation**: 
    - Fixed **Timezone Mismatch** issues in news publication dates (IST conversion).
    - Improved **Sentiment Merging** logic with forward-fill and neutral-pad (0) handling for trading holidays.

## 📦 Installation

### 1. Clone & Setup
```bash
# Clone the repository
git clone <repository-url>
cd stocksense-ai

# Create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Configure Environment Variables
Create a `.env` file in the root directory and add your API keys:
```env
# Get a free API key at: https://newsdata.io/register
NEWSDATA_API_KEY=your_api_key_here
```

## 🚦 How to Use

1.  **Run the App**:
    ```bash
    streamlit run app.py
    ```
2.  **Enter Ticker**: Type any NSE ticker (e.g., `TCS.NS`, `RELIANCE.NS`, `INFY.NS`) in the sidebar.
3.  **Fetch & Analyse**: Click the **🚀 Fetch & Analyse** button. The app will:
    - Download last 2+ years of stock data.
    - Scrape recent financial news.
    - Run FinBERT inference.
    - Train/Load the three AI models.
4.  **Explore Tabs**: Navigate through the dashboard to compare models and study sentiment impact.

---

## 📂 Project Structure

- `app.py`: The main Streamlit dashboard and UI logic.
- `model_trainer.py`: Core logic for LSTM, Random Forest, and SVM training/prediction.
- `sentiment_utils.py`: News fetching (newsdata.io) and FinBERT inference engine.
- `ticker_mapper.py`: Handles ticker-to-company name mapping for Indian stocks.
- `*.keras` / `*.pkl`: Saved model checkpoints for the hybrid models.
